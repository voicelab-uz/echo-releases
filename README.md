# Echo for macOS

Official download artifacts and cryptographically signed update feeds for Echo.

## Test releases

Releases marked **Pre-release** are for update testing. They do not update stable installations automatically.

- macOS 14 or later, on compatible Apple Silicon or Intel Macs.
- Download the universal DMG, open it, and drag Echo into Applications.
- Echo uses Developer ID signing and Apple notarization. Updates are additionally signed with a separate Ed25519 key.
- Use Echo’s **Check for updates…** menu item to check manually. Automatic downloads and installation can be controlled in Settings.

Stable public availability will be announced after update and relaunch testing.

This repository hosts download artifacts and update metadata. It does not contain application source code, credentials, recordings, or account data.
